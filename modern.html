★ HOW TO PLAY ★

  1. Move — press ← → to walk the ball along the free-kick line and open up an angle.
  2. Aim — move your mouse or trackpad over the pitch (or drag on a touchscreen). The target ring follows your pointer. ↑ ↓ fine-tune the height.
  3. Kick — hold SPACE to build power, then release to shoot. The green band on the meter is the sweet spot.
  4. You get 3 attempts, and each one has a 20-second shot clock. If the timer hits zero before you kick, that attempt is counted as missed.
  5. Aim for the corners — top corners score 175, bottom corners 125, a plain goal 100, and perfect power adds a 50-point bonus.
  6. Your total score is added to the global leaderboard and counts toward your team's match total.

Press ENTER after each kick to continue · M mutes sound · R restarts

First-time setup — run this SQL in Supabase, then paste your URL + anon key above 
create table if not exists scores (
  id          bigserial primary key,
  player_name text not null,
  team_id     text not null,
  team_name   text,
  goals       int  default 0,
  attempts    int  default 3,
  score       int  default 0,
  time_ms     int  default 0,
  round_id    text,
  match_id    text,
  created_at  timestamptz default now()
);

create table if not exists tournament (
  id         int primary key,
  state      jsonb not null,
  updated_at timestamptz default now()
);

-- friendly-match rooms (PLAY WITH FRIENDS)
create table if not exists rooms (
  code       text primary key,
  state      jsonb not null,
  updated_at timestamptz default now()
);

alter table scores     enable row level security;
alter table tournament enable row level security;
alter table rooms      enable row level security;

create policy "read scores"    on scores     for select using (true);
create policy "add scores"     on scores     for insert with check (true);
create policy "read bracket"   on tournament for select using (true);
create policy "add bracket"    on tournament for insert with check (true);
create policy "edit bracket"   on tournament for update using (true);
create policy "read rooms"     on rooms      for select using (true);
create policy "add rooms"      on rooms      for insert with check (true);
create policy "edit rooms"     on rooms      for update using (true);

These policies let anyone read and add scores, which is what an open event leaderboard needs. Anyone who views the page can read the anon key, so treat the leaderboard as public and don't reuse this project for confidential data.
